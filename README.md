# Экспертная система: Методы распознавания

> Интеллектуальное веб-приложение для автоматической классификации транспортных средств на «Спорткары» и «Внедорожники». Проект разработан в рамках лабораторной работы №3 по дисциплине "Базы знаний и поддержка принятия решений".

## Описание задачи
Система выступает в роли эксперта, определяя класс неизвестного автомобиля на основе 5 ключевых признаков:
1. Мощность двигателя (л.с.)
2. Время разгона до 100 км/ч (сек)
3. Клиренс (мм)
4. Масса (кг)
5. Расход топлива (л/100 км)

## Реализованные алгоритмы
* **Нормализация данных:** Приведение разнородных признаков к безразмерному виду (от 0 до 1) для корректных математических вычислений.
* **Метод минимального расстояния:** Поиск эталонных "прототипов" для каждого класса и классификация на основе оценки близости к ним (расчет функций D_1 и D_2).
* **Алгоритм восприятия (Перцептрон):** Итеративное машинное обучение разделяющей функции (гиперплоскости), которая безошибочно отделяет один класс от другого.

## Технический стек и Архитектура
Проект построен по принципам чистой архитектуры (Clean Architecture), изолирующей математическое ядро от веб-фреймворка:
* **Domain** (`src/domain/models.py`): Структуры данных и модели распознаваемых объектов.
* **Service** (`src/services/recognition.py`): Бизнес-логика, математические расчеты и алгоритмы машинного обучения.
* **Web** (`src/web/`): REST API на **Flask** и адаптивный графический интерфейс с использованием **Tailwind CSS**.

## Запуск проекта

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Запустите сервер: `python main.py`
3. Откройте в браузере: `http://127.0.0.1:5000`
